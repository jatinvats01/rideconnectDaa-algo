BFS Traversal

Breadth-First Search

Explores all neighbours at the current depth before moving deeper. Uses a queue (FIFO) data structure.

Time: O(V + E) Space: O(V)

DFS Traversal

Depth-First Search

Goes as deep as possible along each branch before backtracking. Uses a stack (LIFO) data structure.

Time: O(V + E) Space: O(V)

Dijkstra's Shortest Path

Weighted Graph Search

Finds minimum-weight path from source to all other nodes using a priority queue.

Time: O((V+E) log V) Space: O(V)
